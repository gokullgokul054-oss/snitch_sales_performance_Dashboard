# 🛍️ SNITCH Fashion Sales Analysis — Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **Power BI Sales Performance Dashboard** created using SNITCH fashion sales data.

The objective of this project is to analyze sales performance, profitability, customer segments, product categories, cities, and overall business performance through an interactive one-page dashboard.

The dashboard helps identify important sales trends and provides a clear view of business performance using KPIs and interactive visualizations.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Track total sales and total profit
- Calculate total orders and units sold
- Analyze profit margin
- Identify top-performing product categories
- Identify top 10 products by sales
- Analyze sales performance across cities
- Compare B2B and B2C sales
- Analyze monthly sales trends
- Create an interactive business dashboard using Power BI

---

# 📈 Dashboard

The Power BI dashboard is designed as a **single-page Sales Performance Dashboard**.

### 🔹 KPI Cards

The dashboard includes the following key performance indicators:

- **Total Sales**
- **Total Profit**
- **Total Orders**
- **Total Units Sold**
- **Total Profit Margin**

---

### 📊 Dashboard Visualizations

#### 1. Monthly Sales Trend

A line chart is used to analyze how sales change across different months.

**Fields:**
- Axis → `Month_Name`
- Values → `Total Sales`

---

#### 2. Sales by Product Category

A column chart shows sales generated by different product categories.

**Fields:**
- Axis → `Product_Category`
- Values → `Total Sales`

---

#### 3. Profit by Product Category

A bar chart compares profit generated by each product category.

**Fields:**
- Axis → `Product_Category`
- Values → `Total Profit`

---

#### 4. Top 10 Products by Sales

A bar chart displays the top 10 products based on sales amount.

**Fields:**
- Axis → `Product_Name`
- Values → `Total Sales`

A **Top N = 10** filter is applied using `Total Sales`.

---

#### 5. Sales by City

A bar/column chart analyzes sales performance across different cities.

**Fields:**
- Axis → `City`
- Values → `Total Sales`

---

#### 6. Sales by Customer Segment

A donut chart compares sales between customer segments such as:

- B2B
- B2C

**Fields:**
- Legend → `Segment`
- Values → `Total Sales`
